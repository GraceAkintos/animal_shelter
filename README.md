# Animal Shelter Management System

Software Engineering project by Solomon Junnuri and Grace Akintoye, Missouri State University.

A web application that helps animal shelters manage animal records, medical and
vaccination history, adoption and foster applications, scheduling, inventory,
volunteers, and reports. Built from our Software Requirements Specification (SRS).
